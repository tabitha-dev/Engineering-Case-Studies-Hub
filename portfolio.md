Tabitha Khadse is a frontend-focused software engineer working with responsive UI, accessibility, developer tooling, healthcare workflow design, AI evaluation and automation. The hub presents project demos, implementation trade-offs and engineering evidence. Healthcare prototypes use synthetic or illustrative data and should not be mistaken for deployed patient or billing systems.
